## Neues Design und überarbeiteter Editor

### Neue Funktionen

- **Sprecher Erkennung**: Sprecher werden wenn möglich bei der Transkription automatisch erkannt.
- **Sprecher-Spuren im Editor**: Segmente werden als farbige Blöcke auf einer Zeitleiste angezeigt. Blöcke lassen sich verschieben, in der Länge anpassen und per Drag-and-drop einem anderen Sprecher zuweisen.
- **Automatische Titel**: Für jede Übersetzung wird automatisch ein Titelnamen erstellt.
- **Direktes Bearbeiten im Text**: Der Transkript-Text wird wie in einem Dokument mit normalem Cursor bearbeitet. Änderungen werden automatisch gespeichert und sind über Rückgängig/Wiederholen abgedeckt.
- **Mitlese-Karaoke Hervorhebung**: Während der Wiedergabe wird das aktuell gesprochene Wort hervorgehoben — im Editor und im Betrachter.
- **Klick zum Abspielen**: Ein Klick auf ein Wort springt an die entsprechende Stelle in der Aufnahme.
- **Wortschatz**: Korrigierte Wörter werden automatisch gemerkt und verbessern künftige Transkriptionen.
- **Screen Audio Recording**: Bei Browsern, welche diese Funktion unterstützen (z.B Edge) kann man das Screenaudio zusammen mit dem Mikrofon aufnehmen. Dies erlaubt Transkripte von Meetings.

### Verbesserungen bei der Erkennung

- **Verbesserte Sprechererkennung**: Weniger fehlende Sprechsegmente und bessere Erkennung.
- **Bessere Übersetzung bei mehreren Sprachen**: Mehrere Sprachen werden besser unterstützt.
